# Active Batch

> Current batch of tasks running in parallel. Updated by Claude at the start of each planning session.

---

## Status

No active batch. Start one with the Batch Planning Playbook.

---

## How it works

1. During a planning session, Claude breaks your week into tasks
2. Each task becomes a separate Claude Code session (parallel execution)
3. Claude writes status here as tasks complete
4. You get an ntfy notification when the whole batch is done

See [[Notes/Playbooks/Batch Planning Playbook]] for the full workflow.
