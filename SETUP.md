# Setup — 3 steps

1. Install [Obsidian](https://obsidian.md) (free)
2. Install [Claude Code](https://claude.ai/code) (free tier available)
3. Open Claude Code, paste the contents of **FIRST_MESSAGE.md** as your first message

That's it. Claude handles every technical step from there.

---

## What happens after you paste FIRST_MESSAGE.md

1. Claude asks you 3 groups of questions — who you are, what you do, how you operate
2. After you answer, it installs everything automatically: vault, hooks, config, semantic search
3. Your vault opens in Obsidian
4. Claude personalizes CLAUDE.md with your real info
5. Restart Claude Code — your system is live

**Total setup time: under 60 minutes**

---

## What's included

- **Obsidian vault** with the full folder structure
- **CLAUDE.md** — the behavior blueprint Claude reads every single session
- **Auto-memory system** — Claude updates notes automatically on every message
- **Hook system** — 5 hooks that make Claude smarter on every prompt
- **Rule engine** — 10 universal rules injected automatically based on what you're doing
- **3 core skills** — voice model, self-learning, client delivery
- **Batch Planning Playbook** — how to plan a week of work in one session

---

## Requirements

- macOS (the hooks use bash — Linux works too, Windows requires WSL)
- Python 3.10+ (usually pre-installed)
- Homebrew (Claude will install it if missing)

---

## Optional: ntfy notifications

Install the [ntfy app](https://ntfy.sh) on your phone. During setup, Claude will give you a topic name. Subscribe to it. You'll get a push notification when Claude finishes long tasks.
