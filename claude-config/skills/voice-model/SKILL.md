# Your Voice Model

> This file is a living document. Update it every time you edit a draft, rewrite something, or use a new phrase. It learns from every interaction.

---

## Hard Rules (violating any of these = rewrite)

1. **No em dashes.** Never. Use commas, periods, or rewrite the sentence.
2. **No AI filler.** No "I'd be happy to", "I wanted to reach out", "I hope this finds you well", "looking forward to", "please don't hesitate". If a default AI response would say it, cut it.
3. **No formal sign-offs.** Never "Best regards", "Kind regards", "Warm regards". Only your name or nothing.
4. **No corporate structure.** No bullet-pointed value props in messages. No "I'm writing to..."
5. **Line breaks between thoughts.** Each idea gets its own line. No walls of text.
6. **Contractions always.** "I'm", "you'd", "it's", "won't". Never the expanded form.

## Message Structure by Context

### Cold outreach (first message)
```
[personal hook or context]...

[1-2 sentences about what you do, casually]

[the offer or ask, clear and direct]
```
Length: 4-6 lines. Max 80 words.

### Reply to interest
```
[acknowledge what they said, briefly]

[reference their specific situation]

[steer toward next step — call, demo, whatever makes sense]
```
Never list everything you'd do for them. Keep the curiosity loop open.

### Follow-up (no reply yet)
One line max. No re-pitch. They already know the offer.

Good:
- "hey [name], just checking if this got buried"
- "[name]?"
- "still interested?"

Bad (never):
- Re-explaining the offer
- "I looked into your company and noticed..."
- Any paragraph in a follow-up

## Self-Improvement Protocol

After every outreach interaction:

- **You edited the draft:** What changed? Why? Add the pattern as a new rule or example. Do it NOW, not next session.
- **You sent it as-is:** The voice model was correct. Note what context category it matched.
- **You rewrote entirely:** The draft failed. Analyze why. Update this file.
- **You used a new phrase:** Add it to the examples section.

Track informally: if most drafts get sent as-is, the model is working. If most get edited, something needs updating.
