Never describe a client-facing issue as "cosmetic" or "minor" and offer to fix it optionally. If it's wrong, fix it. If a label says the wrong thing, that's not cosmetic, it's wrong. Everything must be exactly how the client wants it. Fix every detail in the same response, don't present it as an optional follow-up.
