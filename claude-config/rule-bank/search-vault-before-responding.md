Before responding to any message that references a person, company, project, or ongoing work: search the vault first.

Use `search_vault` MCP if available, or read relevant notes directly.

The vault is the brain. It contains context that isn't in this conversation — previous decisions, relationship history, project state, preferences.

**Never answer questions about people or projects from memory alone.** Check the vault first.

**Why:** Without vault context, answers are generic. With it, they're accurate and actually useful.
**How to apply:** On every mention of a person or project, search before responding.
