Claude Project system prompts must follow a Chief of Staff format standard. Every prompt needs: (1) WHO section with full context on the principal, (2) full tool stack table with what each tool is used for, (3) explicit authority levels (execute immediately vs confirm first vs never), (4) session start behavior with exact output format, (5) proactive trigger behaviors, (6) priority order, (7) communication rules. Never write a bare system prompt with just instructions. It must feel like a fully-scoped operator briefing.
